# 0005 – Lizenz GPL-3.0-or-later

- Status: angenommen
- Datum: 2026-11-02

## Kontext

Der Owner will Open Source.

## Entscheidung

GPL-3.0-or-later.

## Folgen

- Kompatibel mit allen genutzten Bibliotheken (Verovio: LGPL-3.0).
- Code aus MuseScore (GPL-3.0) darf bei Bedarf übernommen werden – z. B. für
  MusicXML-Import oder Notationsregeln.
- Abgeleitete Werke müssen ebenfalls offen sein.
